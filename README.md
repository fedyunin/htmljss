# htmljss

A sandbox for standalone HTML and JavaScript snippets — small self-contained answers to specific problems, each runnable by opening a file in a browser.

> **Archived.** A 2013 scratchpad, not a library. Nothing here has dependencies or a build step.

Open [`index.html`](index.html) for the index.

## Snippets

### limitmeonpage

Limits how long a page may stay open, with a countdown showing the time remaining. When it runs out, the visitor is moved on.

Two pages — [`page1.html`](limitmeonpage/page1.html) starts the timer, [`page2.html`](limitmeonpage/page2.html) is where you land afterwards. Pure JavaScript, no libraries.
